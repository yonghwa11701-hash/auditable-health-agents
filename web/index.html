Auditable health agents

For a lab scientist choosing the next drug combination to screen: three Gemini agents draft a cited shortlist, rule checks written in plain code verify it, and nothing goes ahead until a person approves. Every step is logged.

This page shows a real recorded run and lets you try the rule checks yourself. It makes no model calls and stores nothing you type. Code: github.com/yonghwa11701-hash/auditable-health-agents

Research prototype. Preclinical screening triage on public NCI-ALMANAC cell-line data. Not treatment advice and not a medical device.

How a run works

question -> Orchestrator gemini-4-argon calls the ranking tools -> Research gemini-3.8-flash parallel workers with Google Search grounding -> Rule checks plain Python fixed checks that no model can override -> Checker gemini-3.5-flash-lite second review, structured JSON -> Human sign-off only items that passed can be approved -> Run log one JSON line per model call, tool call, check and decision
